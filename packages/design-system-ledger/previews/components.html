Buttons

Tones.lg-btn--*

Four tones, and exactly one of them is filled with the accent, because a surface with two primary actions has no primary action. Danger is filled too, deliberately: it is only used for the irreversible operations in this product, and a quiet destructive button is a trap.

Sizes--lg-control-sm / md / lg

Three rungs, shared with every other interactive control, so a button and an input sitting side by side always align on both edges. Labels never wrap: a two-line button is a broken button, and the fix is a shorter label rather than a taller control.

Icon and loadingdata-loading

Loading replaces the leading icon with a spinner and keeps the label in place, so the button does not resize mid-request and the cursor does not land on a control that moved.

Chips

Status.lg-chip--*

The only round things in the system. Status is never colour alone: every chip pairs its tone with a text label. Note that "Not satisfied" is a solid ink chip, not a red one, and that "Archived" is dashed so it can never be read as one of the three verdict outcomes.

Dots, versions and roles.lg-dot · .lg-version-pill · .lg-chip--role

Version stamps are square and monospace, unlike every other chip, because they are identifiers rather than statuses. Role tags carry no hue at all: who someone is must never be confused with what an evaluation concluded, so identity is the one thing in this system that is never coloured.

Forms

Fields.lg-field

Label above, help text below the control, error text below that. Never a placeholder standing in for a label: a placeholder disappears the moment the user types, which means the one piece of text explaining what a field wants is gone exactly when they are trying to fill it in.

Containers

Card and well.lg-card · .lg-well

Cards are bounded by rules, never lifted: nothing in this system uses a shadow to say "this is a group". The well is cut into the page instead, and holds data the system read rather than chrome the app wrote. Keeping those two visually opposed is what makes "this is what was actually read" legible.

Table.lg-table · .lg-scroll-x

Ruled, not striped. Zebra rows fight with status chips for the reader's attention, and in a table whose whole job is to carry status that is a bad trade. Always wrapped in .lg-scroll-x, so wide content scrolls inside its own container and the page body never scrolls sideways.

Navigation.lg-tabs · .lg-breadcrumb · .lg-nav-item

Tabs scroll horizontally rather than wrapping, because a two-line tab bar reorders itself as the label set changes and destroys the muscle memory that is most of what tabs are for. The active nav item carries a left rule and a weight change as well as the accent tint, so it stays legible without relying on hue.

Feedback

Alerts.lg-alert--*

No coloured band down the left edge. Tone is carried by the icon, the tinted background and the words. The danger tone means the run did not finish, and it says nothing about whether the code satisfies the requirement, which is why a negative verdict never uses it.
